# OEC Cross-Witness Cycle — source-safe synthetic integration

**Purpose:** A P0 integrated *vertical-slice* test that earns its evidence by driving a real action and independently checking observable effects rather than merely reporting that components started. Follow the owner-approved [COA C](https://github.com/SemperSupra/suprachat-private/blob/main/worksets/oec-observatory/COA-C-EXECUTION-PLAN-20261103.md).

Runs only on a disposable public Ubuntu GitHub Actions runner. No private repository is checked out. No GitHub writes beyond Actions receipts. No real ChatGPT browsing, saved browser profiles, model credentials, user data, release or deployment.

## Observed scenario

1. Generate runner-local random bearer token and a synthetic `experiment_id`. Start the merged standalone Go OEC Observer MCP on loopback with fixed seven-tool allowlist. Reject wrong-token and arbitrary shell operations.
2. Invoke upstream MCP Inspector CLI to list the actual seven-tool catalog; this proves contract discovery, not hidden ChatGPT internals.
3. A locally hosted original HTML page has a single `Run admitted synthetic event` control. It has no access to the token. When Playwright MCP clicks the button, a bounded proxy forwards exactly one `mirror.experiment` action to the Go Observer server. The only effect is a counter increment from 0 to 1 with idempotent retry.
4. A *different* isolated Chrome DevTools MCP/browser process visits the same synthetic fixture; it must independently observe the resulting counter, associated HTTP request and console marker. This independent witness is still only independent at browser-process level; backend remains shared.
5. Node submits metadata-only OTLP/HTTP spans (one parent action, one child browser witness) with the same synthetic experiment ID to a disposable official OpenTelemetry Collector. The runner reads back collector debug output to verify both named spans and the ID.
6. A source-owned oracle verifies schema, exact experiment ID, trace ID derivation, state before/after, browser conditions, wrong-bearer rejection and prohibited claims, then uploads a redacted JSON receipt. No upstream browser content or bearer ever becomes a public artifact.

## Critical acceptance

Must have: actual MCP Inspector discovery, actual OEC state transition caused by the Playwright action, separate DevTools observation/network/console, actual collector readback and authorization negative; all bound to one synthetic experiment ID. A missing witness or unmatched state is a *FAIL*, not an UNKNOWN accepted as PASS.

Deliberate limitations: the OTLP spans are generated by the synthetic harness **after** the observed actions; this is causal correlation over explicitly instrumented code, not cryptographic independent attestation or observation of hidden model inference. The two browser witnesses share one test fixture and one runner; they do not prove provider independence. No Chrome/Playwright remote control over Cloudflare is exposed.

## Supply chain and merge gate

The first research iteration pins top-level package versions and sets `npm install --ignore-scripts`, but **does not yet have a committed full integrity lockfile**. The collector image is version-tagged, not digest-pinned. These are explicit P0 pre-merge corrective gates even after a functional end-to-end pass. Add a reviewed lockfile and immutable image digest in separate source-owner corrective workcells; rerun exact-head Actions. Do not bypass global required CI or protected source ownership.

**Custody:** public source+synthetic tests; sanitized bounded receipt (7d) in public Actions; durable JSON receipt/hash manifest in approved Git/DLE before expiry; original rights-cleared larger binaries in private Drive if genuinely needed. First failures and next baton are recorded in the private owning DLE.

**Human, automation, agent parity:** the repo README communicates scope and refusals, machine-readable `receipt.json` is stable versioned evidence, and the DLE provides control-plane/next-work authority. EN/DE/TH localization is reserved for actual presentation surfaces, not the invariant machine contract.
